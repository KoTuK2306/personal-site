## 🔍 SEO-оптимизация

Сайт полностью подготовлен для индексации:

| Элемент | Описание |
|---------|----------|
| **Meta-теги** | `description`, `keywords`, `author`, `robots`, `geo`, `language` |
| **Open Graph** | Превью для Facebook, VK, Telegram (`og:title`, `og:description`, `og:image`) |
| **Twitter Cards** | `summary_large_image` для Twitter/X |
| **Schema.org** | JSON-LD разметка: `Person`, `ProfilePage`, `WebSite` |
| **Canonical** | `https://dim0n-c0de.site/` — основной URL |
| **Hreflang** | `ru` + `x-default` |
| **Favicon** | SVG-иконка + `apple-touch-icon` + `mask-icon` |
| **robots.txt** | Разрешение индексации + ссылка на sitemap |
| **sitemap.xml** | Карта сайта с приоритетом и датой обновления |
| **rel="me"** | Верификация профилей через ссылки |

### Регистрация в поисковиках

1. **Google Search Console**: [search.google.com/search-console](https://search.google.com/search-console) — добавь свой сайт и подтверди через HTML-тег или файл
2. **Яндекс.Вебмастер**: [webmaster.yandex.ru](https://webmaster.yandex.ru) — добавь сайт и подтверди владение
3. **Bing Webmaster**: [bing.com/webmasters](https://bing.com/webmasters) — импортирует данные из Google Search Console
